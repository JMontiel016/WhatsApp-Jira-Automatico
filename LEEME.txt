TICKETBRIDGE - RECUPERACIÓN DE INTERFAZ v6.6

Objetivo: recuperar los ajustes visuales del frontend conocidos de v6.4 + v6.5, y permitir reaccionar a los mensajes sin que el selector de emojis quede oculto por el scroll.

Incluye: filtros de WhatsApp, chats/contactos, búsqueda, contadores, fijados y favoritos, control de apariencia, tickets en modal, visor y adjuntos de Jira, botones para responder, imágenes al enviar, Enter para enviar, Ctrl+Enter para nueva línea y reacciones visibles.

Este paquete solo reemplaza:
- app/page.tsx
- app/globals.css

NO modifica: whatsapp/connector.cjs, base de datos, data/, archivos multimedia, .env.local, sesiones, rutas de API ni creación de tickets.

ADVERTENCIA: no se conoce la versión exacta que se encuentra actualmente en tu equipo. El instalador toma una copia de tus dos archivos antes de sustituirlos. Si agregaste personalizaciones al frontend después de la v6.5, no apliques este ZIP sin revisar porque sustituiría esos cambios.

PASOS:
1) Extraer ZIP en una carpeta aparte.
2) Comprobar sin cambiar nada:
   bash instalar-recuperacion-interfaz.sh "$HOME/Escritorio/whatsapp-jira"
3) Si aceptás recuperar la última interfaz conocida:
   bash instalar-recuperacion-interfaz.sh "$HOME/Escritorio/whatsapp-jira" --aplicar
4) En proyecto: Ctrl+C en Next.js, luego rm -rf .next && npm run dev
5) Navegador: Ctrl+Shift+R

Rollback: el instalador informa ruta del respaldo en .ticketbridge-backups/recuperacion-interfaz-v66-.../app. Para deshacerlo, copiar page.tsx y globals.css del respaldo a app/ y reiniciar Next.js.

LIMITACIÓN IMPORTANTE: esto solo recupera la interfaz de las funcionalidades que ya existen. NO garantiza resolver la descarga multimedia fallida ('t') del conector WhatsApp.
